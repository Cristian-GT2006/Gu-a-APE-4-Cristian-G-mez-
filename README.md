## Detalle de los Ejercicios

### Ejercicio 1: Libro y Autor
* **Enfoque:** Objeto como atributo[span_14](start_span)[span_14](end_span).
* **Enunciado:** Crea la clase `Autor` (nombre, nacionalidad) y la clase `Libro` (titulo, anio, autor). Libro debe tener un atributo de tipo `Autor` y un metodo `mostrarInformacion()` que imprima el titulo, el ano y el nombre del autor. En el metodo `main`, crea 2 libros[span_15](start_span)[span_15](end_span).

### Ejercicio 2: Rectangulo
* **Enfoque:** Firmas de metodos[span_16](start_span)[span_16](end_span).
* **Enunciado:** Crea la clase `Rectangulo` (base, altura) con los siguientes metodos, usando el tipo de retorno correcto en cada firma: `calcularArea()`, `calcularPerimetro()`, `esCuadrado()`, `obtenerDescripcion()` (devuelve una cadena como "Rectangulo de 4.0 x 6.0") y `mostrar()` para imprimir todos los resultados[span_17](start_span)[span_17](end_span).

### Ejercicio 3: Producto y Venta
* **Enfoque:** Objeto como parametro[span_18](start_span)[span_18](end_span).
* **Enunciado:** Crea la clase `Producto` (nombre, precio, stock) con el metodo `reducirStock(int cantidad)` (que solo actua si hay stock suficiente; si no, imprime "Stock insuficiente.") y `mostrarProducto()`. Crea la clase `Venta` (cantidad) con el metodo `aplicar(Producto producto)` que reduzca el stock y muestre el total a pagar[span_19](start_span)[span_19](end_span).

### Ejercicio 4: Transferencias
* **Enfoque:** Objeto como parametro y validacion de estados[span_20](start_span)[span_20](end_span).
* **Enunciado:** Usa la clase `Cuenta` y agrega el metodo `transferir(Cuenta destino, double monto)`, que retire el monto de la cuenta actual y lo deposite en la cuenta destino solo si hay fondos suficientes. En el `main`, crea 2 cuentas, realiza una transferencia valida y otra que falle[span_21](start_span)[span_21](end_span).

### Ejercicio 5: Biblioteca
* **Enfoque:** Colaboracion entre clases[span_22](start_span)[span_22](end_span).
* **Enunciado:** Crea tres clases que colaboren entre si: `Usuario`, `Libro` y `Prestamo`. `Prestamo` tiene atributos de tipo `Usuario` y `Libro`, y su metodo `registrar()` intenta prestar el libro y muestra un mensaje segun el resultado. En el `main`, haz que dos usuarios intenten pedir el mismo libro[span_23](start_span)[span_23](end_span).
